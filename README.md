# Rural clinic website — design mock-up

Static concept mock-up of a general practice website (home, about/team, services,
fees, patient information, repeat prescription & referral request forms, contact).

Not a live clinic website. All content is draft copy or a labelled placeholder;
no real contact details, fees, hours, names or qualifications appear anywhere.
All forms are deliberately inert — no `action`, no field `name` attributes,
no backend, nothing is transmitted or stored.
